# Jericho Forests — غابات أريحا

Scroll-driven landing page for private chalets in Jericho. React, Vite, Tailwind CSS, GSAP + ScrollTrigger.

- Pinned hero: day → sunset → night as you scroll
- Words light up as you read
- Horizontal chalet gallery driven by vertical scroll
- Counting numbers

## Run
```bash
npm install
npm run dev
```

Edit `src/data/chalets.js` for a new place. Add real photos in `public/images` and set `image` on each chalet.
